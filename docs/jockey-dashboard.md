# 騎手成績ダッシュボード

`/jockeys` で騎手名を部分一致検索し、保存済みの騎手成績を確認できる。
ヘッダーの「騎手成績」と、レース詳細の出馬表にある騎手名から開く。

## 検索と表示

- 騎手マスターの名前と、関連する成績行の騎手名で検索する。候補が1件なら成績を表示し、複数なら選択する。候補は20件まで表示する。
- 初期表示では検索を実行しない。検索語は前後の空白を除き100文字以内とし、重複パラメータや不正な騎手IDではDBに問い合わせない。
- 騎手IDを指定したリンクは、その騎手の成績を直接表示する。
- 騎手マスターに紐づいた `JockeyRacecourseRecord` を使う。集計のない騎手、未集計の条件、検索結果なし、取得エラーは別の案内を表示する。
- 期間・競馬場・芝ダート・距離帯のGETフォームで絞り込む。検索語、騎手ID、絞り込み条件はURLに保持する。
- 騎乗数、勝率、連対率、複勝率と1〜3着の件数、対象レースの日付、集計更新日時を表示する。日付列はUTC、更新日時はJSTで整形する。
- 競馬場別・芝ダート別・距離帯別の表は、比較する軸以外の選択条件を固定する。

## 集計の扱い

`all` は保存済みのまとめ行を指す。まとめ行と内訳行を合算すると二重計上になるため、選択した条件に完全一致する行を使う。
同じマスターの別表記に同条件の行がある場合は、生成日時が新しいものを使い、合算しない。

出馬表と異なり、騎乗数が20未満でも条件を広げない。実際の件数・割合に参考値の注意を添え、内訳表では「少数」と表示する。
騎乗数が0の行では割合を算出できないため「—」と表示する。
率の定義は、勝率が1着、連対率が2着以内、複勝率が3着以内の件数を騎乗数で割った値。

DBアクセスは `src/app/lib/jockeyDashboardData.ts`、条件の検証と表示用の選択は `src/app/lib/jockeyDashboard.ts` に分ける。
既存テーブルを参照するため、マイグレーションとpredictorの変更は不要。

## 確認手順

1. ヘッダーの「騎手成績」から検索画面を開く。
2. 保存されている騎手の名前を入力し、候補が1件なら成績、複数なら選択肢が表示されることを確認する。
3. 競馬場・芝ダート・距離帯を変更し、選択条件の成績と内訳表を確認する。未集計の条件では別条件の数字を表示しないことも確認する。
4. 出馬表の騎手名から同じ騎手の成績を開く。
5. モバイルで表が枠内を横スクロールすることと、ライト／ダークの両テーマを確認する。
